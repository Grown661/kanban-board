# Kanban Board

**Live-Demo:** https://grown661.github.io/kanban-board/

Aufgaben verteilen sich schnell über Notizzettel und Chats – dieses Board hält sie als Karten in Spalten, verschiebbar per Drag & Drop, komplett lokal im Browser.

## Features

- Standard-Spalten (Todo / Doing / Done) plus beliebige eigene Spalten
- Karten anlegen, bearbeiten (Doppelklick), löschen
- Natives HTML5 Drag & Drop zwischen Spalten und innerhalb einer Spalte (Reihenfolge)
- Reihenfolge und Inhalte bleiben persistent (localStorage)
- Export und Import als JSON

## Stack

- HTML, CSS, Vanilla JavaScript
- Keine Abhängigkeiten, keine Build-Kette

## Setup & Start

`index.html` im Browser öffnen – fertig.
